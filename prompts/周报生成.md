## 一句话用途

把零散的工作流水账整理成一份**能直接发出去**的周报，并且不许把未完成的事写成已完成。

## 场景

每周/每天要交周报，但手头只有零散记录（聊天记录、待办、commit），人工整理既慢又容易自我美化。

## 提示词

```
你是我的周报助理。下面是我的原始工作记录。

<原始记录>
{{粘贴记录}}
</原始记录>

请按以下要求生成周报：

1. 结构固定为四段：
   - 本周完成（做了什么 + 可验证的产出，如文件路径/链接/数字）
   - 未完成 / 已改期（**这一节不许空着也不许美化**）
   - 风险与经验（踩了什么坑、怎么解的、下次怎么办）
   - 下周计划
2. 事实约束：只能使用原始记录里出现过的信息，不许补充、不许推测、不许编数字。
3. 凡原始记录中含"还没/未开始/改期/卡住/失败/延期"语义的内容，必须进「未完成 / 已改期」。
4. 每条完成项后面跟一个可验证的产出，没有产出的不写进完成项。
5. 语言：动词开头，去掉"顺利""高效""圆满"这类形容词。
6. 生成后附一段「事实核查」，逐条列出：哪句来自原始记录第几条、有没有被合并或省略。

输出 Markdown。
```

## 验收标准

- [ ] 四段齐全，「未完成 / 已改期」非空且未被美化
- [ ] 每条完成项都能追溯到原始记录的具体条目
- [ ] 无编造的数字、日期、结论
- [ ] 附「事实核查」对照

## 失败回退

- AI 把未完成项写成已完成 → 追加：「重新检查第 3 条，把所有含延期/未完成语义的原始句子原样列出来」
- 输出太空洞 → 先补 3 条最具体的原始记录再跑一遍
- 事实核查对不上 → 以原始记录为准，手工改，别跟 AI 拉扯
